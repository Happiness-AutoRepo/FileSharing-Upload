Direct GitHub Upload

Uploads directly to the private Happiness-AutoRepo/FileSharing repository via GitHub's API. Use only for authorized uploads.

Requires access to FileSharing and Contents: Read and write. This page never stores the token.

Files are added to a new monthly folder under uploads/browser-YYYY-MM/. The existing Cloudflare uploader remains available. GitHub login is not required on this page, but a valid repository token is required.
